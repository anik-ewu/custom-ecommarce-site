# Demo video script (about 3 minutes)

Record at 1440×900 in the browser, with a phone-size window ready for the mobile part.

1. **Home (15 s).** "Nokshi Kathar Math sells handmade nakshi kantha and jute from Bangladesh." Scroll slowly: hero, one-of-a-kind
   pieces, category tiles, artisans, trust row. Point out the running-stitch dividers.
2. **Catalog (20 s).** Shop → filter by Kantha Cushions → sort by price → search "lotus". Mention skeleton loading
   and that filters are shareable URLs.
3. **One-of-a-kind hold (35 s).** Open a cushion, Add to cart: the drawer shows "Held for you · 14:59".
   In a second (private) window open the same piece: "Another shopper is holding this piece."
   Say: "A single atomic upsert decides who gets it; we test this with ten shoppers racing."
4. **Checkout (40 s).** Checkout → sign-in wall → Try the demo as a shopper (cart comes along) → delivery form with
   Bangladeshi mobile validation → Place order → thank-you page. Back on the product: "This piece has found its home."
5. **Account (15 s).** Account → order history → order detail with the progress line.
6. **Admin (40 s).** Sign out → Try the demo as an admin → Dashboard (sales, pending, low stock) → open the order →
   Mark confirmed → Mark shipped. Products → edit stock → add a photo with alt text.
7. **Mobile and accessibility (20 s).** Phone-size window: sticky buy bar on the product page, cart drawer, checkout.
   Tab through a page to show the dashed stitch focus ring.
8. **Close (15 s).** Show the README's design decisions and the green CI run: "Real Postgres in tests, the race and
   rotation cases covered, free-tier friendly."
